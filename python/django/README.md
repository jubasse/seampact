# seampact-django

The Django layer shared by the seampact DRF and Ninja targets: URLconf and settings emitters and the runtime of generated code.

```sh
pip install "seampact-django[generate]"
```

Guide: https://jubasse.github.io/seampact/concepts/packages/

The Django layer the seampact DRF and Ninja targets share: the URLconf, settings and boundary emitters, the `seampact.django` app and the Django runtime of generated code.
