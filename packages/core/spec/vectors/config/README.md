The app config cases every config reader (Node, PHP, JVM, Python) proves itself on: in `use-forms.json`, each accepted `use` of a target entry with the runner it belongs to, and each refused one, which the schema rejects with the rule of the `pypi:<distribution>` form (ADR 0011 "The app config"); in `out-directories.json`, the `out` of two target entries under one `outDir` and the codes the reader refuses them with, case folded as the writers fold generated paths (ADR 0015 "Writing files").
