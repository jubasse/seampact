# seampact-fastapi

Seampact target for FastAPI: its generator and the placement runtime of the server code it generates.

```sh
pip install "seampact-fastapi[generate]"
```

Guide: https://jubasse.github.io/seampact/backend/fastapi/

The FastAPI target of seampact: the generator that `seampact generate` finds through its entry point, and the runtime the generated placement imports.
