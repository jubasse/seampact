The Spring Boot consumer (ADR 0022 "The consumer and the proof"): a Spring Boot 4 app built by the Gradle plugin from the reference contract, its controllers, hook doubles and control routes, and the suite run that checks it with the shared http suite.

- `assemble.sh <dir> [allow-listed|pack-spring]` copies the app, its Gradle build root, the Gradle wrapper and the reference contract into `<dir>`; `allow-listed` takes the config of the `allow-listed-framework-route` boot variant; `pack-spring` takes the contract with `@seampact/pack-spring` applied, `pack-spring/src` (its paged lists answer Spring Data's `Page`) and Spring Data Commons.
- In `<dir>`: `./gradlew test bootJar -PseampactJvm=<repo>/jvm -PseampactBinary=<binary> [-PjavaVersion=25]` runs `GeneratedRedactionTest` and builds `build/libs/consumer.jar`; the plugin and `seampact-hooks` come from the repository's `jvm/` build, included by path.
- From the repository root, with `SEAMPACT_SPRING_JAR`, `SEAMPACT_SPRING_ALLOW_LISTED_JAR`, `SEAMPACT_SPRING_PACK_JAR` and `SEAMPACT_SPRING_REPORTS` set: `pnpm vitest run --config scripts/consumers/targets/spring-boot/suite/vitest.config.ts` runs the `default`, `hand-written`, `boot` and `pack:spring` profiles and a forwarded-prefix check, and writes one report per profile. `suite/suite-refusals.ts` lists the cases a profile does not run, with the reason.
