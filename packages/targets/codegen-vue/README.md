# @seampact/codegen-vue

Seampact target for Vue: generates TanStack Query or Pinia Colada options and composables, or plain fetch composables, over the typed fetch client.

```sh
npm install --save-dev @seampact/codegen-vue
```

Guide: https://jubasse.github.io/seampact/frontend/vue/

Generates TanStack Query or Pinia Colada options and Vue composables, or plain fetch composables with no query library, over the typed fetch client, with keys, invalidation and paging read from the contract.
