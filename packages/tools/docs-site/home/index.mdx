## Install

The command line and the generators come from your ecosystem's registry, at the same version.

<Tabs syncKey="ecosystem">
  <TabItem label="npm">
    ```sh
    npm install --save-dev @seampact/cli @seampact/codegen-ts
    ```
  </TabItem>
  <TabItem label="Gradle">
    ```kotlin
    // build.gradle.kts
    plugins {
        id("io.github.jubasse.seampact") version "1.0.0"
    }
    ```
  </TabItem>
  <TabItem label="Maven">
    ```xml
    <!-- pom.xml -->
    <plugin>
      <groupId>io.github.jubasse</groupId>
      <artifactId>seampact-maven-plugin</artifactId>
      <version>1.0.0</version>
    </plugin>
    ```
  </TabItem>
  <TabItem label="Composer">
    ```sh
    composer require seampact/laravel seampact/hooks
    # Symfony: composer require seampact/symfony
    ```
  </TabItem>
  <TabItem label="pip">
    ```sh
    pip install "seampact-fastapi[generate]"
    # Django REST Framework: seampact-drf, Django Ninja: seampact-ninja
    ```
  </TabItem>
</Tabs>

Each ecosystem has its own steps: [Install in other ecosystems](/seampact/getting-started/install-other-ecosystems/).
