The reader parity corpus (ADR 0010): `cases.json` holds IR documents, written by `scripts/ir-models` (`--write`), each with the verdict of the TypeScript reader (accept, malformed, not-json, or refuse with every refusal sorted by member then code, never the message), which the Kotlin and PHP readers must give too. A case is an `example` of `schemas/ir/examples/`, its `edits` (a value set or removed at a JSON Pointer), its `literals` (number or bare-token text written into the document as given) and a named `support` declaration; the refusal code `ir.must-act.unknown` (member: the tag member or the value) is the corpus name for an unknown tag or value of a must-act definition. A refusal holds its `code` and `member`, its `value` when that is a string (a number is not compared, since the platforms render numbers apart), and, for a support refusal, its `expected` list as text and its `operation` when it has one; a native reader compares each field the refusal records, and the `operation` of every support refusal. `not-json` is text JSON refuses, a bare token such as `3d` or `NaN` included: every reader fails on it as malformed.

`role-params.json` holds render vectors, not reader verdicts: each case is an error role binding's compiled template, the role data a target supplies, the code's params schema and the params the target renders (ADR 0004 section 7), or the invariant a refused template breaks and, in `refusedAt`, the pointer of the violation below the template; every server target's renderer gives those params. `header-values.json` holds render vectors too: each case is an IR fragment and its request data with the exact text of the `Deprecation`, `Sunset`, successor `Link`, degraded-parts or retry header a target writes (`null` when it writes none), or the invariant a refused fragment breaks and, in `refusedAt`, the pointer of the violation below the fragment; a `.` or `..` path param stays as is, since both are RFC 3986 `unreserved`, and the link then resolves on the same origin; targets run it under a non-UTC `TZ`.
