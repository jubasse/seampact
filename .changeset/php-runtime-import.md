The Laravel and Symfony targets no longer copy their runtime into each api: the generated code imports `Seampact\Codegen\Runtime` and `Seampact\<Target>\Runtime` from the installed `seampact/laravel` or `seampact/symfony` (now a production `require` for Symfony too), each api gets its own `UnexpectedErrorListener` interface and idempotency store key (and on Symfony its own `SeampactOperation`, `Decider` and `ScopeResolver`), and every boot but `seampact:generate` refuses code generated by another seampact minor or a later patch (`runtime.generated-for-other-version`).
