# seampact-ninja

Seampact target for Django Ninja: its generator and the placement runtime of the server code it generates.

```sh
pip install "seampact-ninja[generate]"
```

Guide: https://jubasse.github.io/seampact/backend/ninja/

The seampact Django Ninja target: the `seampact-ninja` generator, found through the `seampact.generators` entry point, and the Ninja runtime of the code it generates.
