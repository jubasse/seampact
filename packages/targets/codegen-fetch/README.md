# @seampact/codegen-fetch

Seampact target that generates a typed fetch client with one method per operation, returning success and error responses as typed results.

```sh
npm install --save-dev @seampact/codegen-fetch
```

Guide: https://jubasse.github.io/seampact/frontend/react/

Generates a typed fetch client with one method per operation, returning its success and error responses as typed results.
