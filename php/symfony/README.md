# seampact/symfony

Seampact target for Symfony 7.4 and 8: generates the types, controller interfaces, routes, constraints and bundle of an API contract.

```sh
composer require seampact/symfony
```

Guide: https://jubasse.github.io/seampact/backend/symfony/
