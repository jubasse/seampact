# @seampact/codegen-angular

Seampact target for Angular: generates an injectable api service over HttpClient with signal readers, and opt-in NgRx actions and effects.

```sh
npm install --save-dev @seampact/codegen-angular
```

Guide: https://jubasse.github.io/seampact/frontend/angular/

Generates an injectable Angular api service over HttpClient with signal readers built on resource(), over the typed fetch client, with no query library, and opt-in NgRx action groups and effects.
