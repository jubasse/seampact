Shared by the Python consumer apps (FastAPI, then DRF): `requirements.sh` writes the hash-pinned third-party requirements from `python/uv.lock`, `install.sh` installs them and the seampact wheels `uv build` wrote into a new virtual environment (ADR 0011 "Unpublished installs for test consumers"), `python-app.ts` serves an assembled app under uvicorn or gunicorn for the suite, `boot.py` runs one boot case under uvicorn, and `suite/seampact_consumer_suite` holds the suite doubles every app copies in: the control state behind `/__seampact/script`, `hook-calls` and `log-lines`, the scripted answers, the credentials and the boot variant.
