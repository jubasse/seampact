Shared by the Python consumer apps (FastAPI, then DRF): `requirements.sh` writes the hash-pinned third-party requirements from `python/uv.lock`, `install.sh` installs them and the seampact wheels `uv build` wrote into a new virtual environment (ADR 0011 "Unpublished installs for test consumers"), `assemble.sh` copies a target's app and the suite doubles into a work directory and points it at the bundled contract, `python-app.ts` serves an assembled app under uvicorn or gunicorn for the suite, `python-http-suite.ts` runs the suite's default, hand-written and boot profiles against it, `boot.py` runs one boot case under uvicorn, `django_boot.py` one boot case of a Django app by importing its WSGI or ASGI module, and `suite/seampact_consumer_suite` holds the suite doubles every app copies in: the control state behind `/__seampact/script`, `hook-calls` and `log-lines`, the scripted answers and decisions, the credentials, the boot variant, a file idempotency store and the `stripe` signature check. `local-yaml.sh` generates and checks a target from the reference contract's YAML through a pinned compiler binary (no bundle, no `openapi` key, so the binary writes the documents), and `channel-smoke.sh` generates from the release and git channels that `scripts/dist-smoke/cli.ts serve` starts and expects each tampered copy to be refused as `bundle.file-hash`.
