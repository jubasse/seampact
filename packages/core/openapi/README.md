# @seampact/openapi

Writes OpenAPI 3.1 documents from a seampact API contract, keeping what OpenAPI cannot say as x-seampact-* extensions.

```sh
npm install --save-dev @seampact/openapi
```

Guide: https://jubasse.github.io/seampact/configuration/openapi-and-docs/

Writes the OpenAPI 3.1 documents from the IR, with what OpenAPI cannot say as x-seampact-* extensions.
