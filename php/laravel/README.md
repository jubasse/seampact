# seampact/laravel

Seampact target for Laravel 13: generates the FormRequests, types, controller interfaces, routes and boundary of an API contract.

```sh
composer require seampact/laravel seampact/hooks
```

Guide: https://jubasse.github.io/seampact/backend/laravel/

The Laravel 13 target: FormRequests, types, controller interfaces, routes and boundary of a contract.
