Test consumers of the packed packages: build, pack, assemble a consumer from the template and a target overlay, then install, generate, typecheck and test it (scripts/consumers). Consumer sources use `.mts` so the monorepo's own typecheck and test globs leave them to the consumer, where they are checked. `--validators <id>` (default `zod`) picks the validator library a consumer generates with, from `validator-choice.ts`. The test step runs the default profile of `@seampact/http-suite` against the server the overlay starts and writes its report to `reports/http-suite-default.json` in the consumer. Each overlay serves the suite's control routes beside the contract routes, from the template's `src/suite-control.mts`; the template's hooks and handlers answer from the script a case loads and record each authenticate and decide call.
