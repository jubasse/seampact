# seampact-drf

Seampact target for Django REST Framework: its generator and the runtime of the server code it generates.

```sh
pip install "seampact-drf[generate]"
```

Guide: https://jubasse.github.io/seampact/backend/drf/

The seampact Django REST Framework target: the `seampact-drf` generator, found through the `seampact.generators` entry point, and the DRF runtime of the code it generates.
