The request checks and replies of a server boundary, built into `@seampact/server-runtime`, which the Express and Hono targets' generated code imports, and copied as is into the generated tree of the targets that do not import it yet (ADR 0016, ADR 0020 "The Web-standard adapter", ADR 0025): neutral modules for every target, `node-` modules (the `ServerResponse` side and the `IncomingMessage` view with the Express body glue) for the Node targets only, `web-` modules for the Web-standard targets only.
