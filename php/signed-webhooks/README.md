# seampact/signed-webhooks

Verifies signed webhooks in a seampact authenticate hook on PHP: HMAC over the raw body, timestamp tolerance and secret rotation.

```sh
composer require seampact/signed-webhooks
```

Guide: https://jubasse.github.io/seampact/concepts/packages/
