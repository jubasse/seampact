The FastAPI consumer (ADR 0026 "The consumer and the proof"): a FastAPI app that `seampact-fastapi` generates the reference contract's tasks and tasksService apis into, serving every operation of both, its handlers, hook doubles (the `user`, `stripe` and `service` identities, the `user` and `service` ones reading their token through FastAPI `Security` schemes, the channel resolver, the deciders, a file idempotency store) and control routes, and the suite run that checks it with the shared http suite under uvicorn.

- `../../php/bundle.sh <binary> <out>` bundles the reference contract with the compiler binary into `<out>/bundle` and writes its integrity pin to `<out>/integrity`; it is the one step that needs the binary.
- `assemble.sh <work> <out> [allow-listed]`, through the shared `../../python/assemble.sh` with `SEAMPACT_CONSUMER_BINARY` naming the compiler binary (the tasks entry's `nativeDocs` emits seampact's document through it), copies `app/`, the shared suite doubles (`../../python/suite`) and the shared `../../python/reference_doubles/hook_doubles.py` into `<work>/app` (`allow-listed`: `<work>/app-allow-listed`, built from `seampact.allow-listed.config.yaml` for the `allow-listed-framework-route` boot variant), commits the bundle into the local git repository `<work>/contract-repo` tagged `v1.0.0` and points the app config at it with the integrity pin (`../spring-boot/contract-source.sh`).
- The install (`../../python/README.md`): `requirements.sh <file> seampact-fastapi generate uvicorn` and `uv build --all-packages --wheel` in `python/`, then `install.sh <venv> <file> <wheels> 'seampact-fastapi[generate]' [python/fastapi/ci/floor-requirements.txt]`, then `seampact-signed-webhooks` from the same wheels; in an assembled app, `<venv>/bin/seampact generate`.
- `app/main.py` binds the tasks api with the handlers of `app/handlers.py` and the shared hook doubles, whose `user` and `service` factories in `app/hooks.py` read the bearer token through FastAPI `Security` schemes, less the binding `SEAMPACT_SUITE_BOOT_VARIANT` names, then the tasksService api; the doubles keep the loaded script, the recorded hook calls and the log lines in `suite-control.json` beside the app.
- From the repository root, with `SEAMPACT_FASTAPI_APP`, `SEAMPACT_FASTAPI_ALLOW_LISTED_APP`, `SEAMPACT_FASTAPI_VENV` and `SEAMPACT_FASTAPI_REPORTS` set: `pnpm vitest run --config scripts/consumers/targets/fastapi/suite/vitest.config.ts` serves the app with uvicorn, runs the `default`, `hand-written` and `boot` profiles and writes one report per profile, and `native-docs.suite.ts` compares the tasks operations of FastAPI's `/openapi.json` with seampact's `openapi/tasks.full.yaml`; a boot is a uvicorn start of the app (`../../python/boot.py`), whose startup runs the boot check. `suite/suite-refusals.ts` lists the cases the consumer does not run, with the reason.
