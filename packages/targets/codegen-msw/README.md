# @seampact/codegen-msw

Seampact target for Mock Service Worker 2: generates handlers per operation that answer the contract's examples or the typed result a test gives.

```sh
npm install --save-dev @seampact/codegen-msw
```

Guide: https://jubasse.github.io/seampact/frontend/msw/

Generates Mock Service Worker 2 handlers per operation that answer the contract's examples, or the typed success or error a test gives, in the api's wire format.
