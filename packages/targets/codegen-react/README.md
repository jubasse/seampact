# @seampact/codegen-react

Seampact target for React: generates TanStack Query or SWR options and hooks, an RTK Query api, or plain fetch hooks over the typed fetch client.

```sh
npm install --save-dev @seampact/codegen-react
```

Guide: https://jubasse.github.io/seampact/frontend/react/

Generates TanStack Query or SWR options and React hooks, an RTK Query api, or plain fetch hooks with no query library, over the typed fetch client, with keys, invalidation and paging read from the contract.
