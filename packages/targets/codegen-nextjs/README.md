# @seampact/codegen-nextjs

Seampact target for Next.js 16: generates a routeHandler per api for a catch-all route with access, validation and reply checks around your handler map.

```sh
npm install --save-dev @seampact/codegen-nextjs
```

Guide: https://jubasse.github.io/seampact/backend/nextjs/

Generates a routeHandler per api that serves a Next.js 16 catch-all route with the contract's access, validation and reply checks around your handler map, validating with zod.
