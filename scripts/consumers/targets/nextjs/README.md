The Next.js 16 consumer: one catch-all route file per base path of the reference apis, built with `next build --webpack` and served by `next start` on the Node.js runtime, running the http suite's default profile (the hand-written and boot profiles wait). Route files are `route.tsx`, and the config `next.config.mts`, so the monorepo's `scripts/**/*.ts` typecheck leaves them to the consumer; the shared sample sources are `.mts` with `.mjs` specifiers, which Turbopack does not resolve, hence webpack here.
