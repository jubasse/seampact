# @seampact/codegen-axios

Seampact target that runs the typed fetch client over your own axios instance, so the React, Vue and Angular targets use axios.

```sh
npm install --save-dev @seampact/codegen-axios
```

Guide: https://jubasse.github.io/seampact/frontend/axios-client/

Generates the typed client of the fetch target over your own axios instance, so the React, Vue and Angular targets run over axios.
