The reader parity corpus (ADR 0010): `cases.json` holds IR documents, written by `scripts/ir-models` (`--write`), each with the verdict of the TypeScript reader (accept, malformed, or refuse with the sorted `code` and `member` of every refusal, never the message), which the Kotlin and PHP readers must give too. A case is an `example` of `schemas/ir/examples/`, its `edits` (a value set or removed at a JSON Pointer), its `literals` (number text written into the document as given) and a named `support` declaration; the refusal code `ir.must-act.unknown` (member: the tag member or the value) is the corpus name for an unknown tag or value of a must-act definition.
