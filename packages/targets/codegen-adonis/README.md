# @seampact/codegen-adonis

Seampact target for AdonisJS: generates routes with checking middleware, the reply path, error helpers and a boot check around your controllers.

```sh
npm install --save-dev @seampact/codegen-adonis
```

Guide: https://jubasse.github.io/seampact/backend/adonisjs/

Generates the AdonisJS boundary around your controllers: the routes of each api with their checking middleware, the reply path, the error helpers for your exception handler and a boot check, validating with the zod or yup link you give or with VineJS validators it generates.
