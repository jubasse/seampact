# @seampact/codegen-ts

Seampact target that generates a TypeScript type per schema and each operation's input, output and error union.

```sh
npm install --save-dev @seampact/codegen-ts
```

Guide: https://jubasse.github.io/seampact/configuration/targets-and-links/

Generates a named TypeScript type per schema and each operation's input, output and error union.
