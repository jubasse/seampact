# @seampact/codegen-yup

Seampact validators for yup: Standard Schema validators per schema and direction, and one input validator per operation.

```sh
npm install --save-dev @seampact/codegen-yup
```

Guide: https://jubasse.github.io/seampact/configuration/validators/

Generates Standard Schema yup validators per schema and direction, and one input validator per operation.
