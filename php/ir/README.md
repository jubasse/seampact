# seampact/ir

Reads a seampact API contract's IR into PHP value types, for the seampact PHP generators.

```sh
composer require seampact/ir
```

Guide: https://jubasse.github.io/seampact/concepts/packages/

Part of [seampact](https://github.com/jubasse/seampact). Documentation: https://jubasse.github.io/seampact/
