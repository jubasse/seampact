# seampact/api-platform

Seampact target for API Platform 5: generates the resources, operations and processors of an API contract on top of the Symfony target.

```sh
composer require seampact/api-platform api-platform/symfony
```

Guide: https://jubasse.github.io/seampact/backend/api-platform/
