# @seampact/codegen-zod

Seampact validators for zod: Standard Schema validators per schema and direction, and one input validator per operation.

```sh
npm install --save-dev @seampact/codegen-zod
```

Guide: https://jubasse.github.io/seampact/configuration/validators/

Generates Standard Schema zod validators per schema and direction, and one input validator per operation.
