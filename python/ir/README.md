# seampact-ir

The seampact IR model, naming and reader for Python generators, with the bundle verifier and the compiler runner.

```sh
pip install seampact-ir
```

Guide: https://jubasse.github.io/seampact/concepts/packages/

The seampact IR model generated from the IR JSON Schema, the native naming, the IR reader, the bundle verifier and the compiler binary runner, for Python generators.
