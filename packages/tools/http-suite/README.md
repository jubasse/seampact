# @seampact/http-suite

The black-box HTTP suite shared by the seampact server targets: JSON case scripts, a runner against a base URL and a report keyed by checklist id.

```sh
npm install --save-dev @seampact/http-suite
```

Guide: https://jubasse.github.io/seampact/concepts/packages/
