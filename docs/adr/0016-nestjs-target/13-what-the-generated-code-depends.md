### What the generated code depends on

At run time: `@nestjs/common`, `@nestjs/core` (its `internal` entry for `ExecutionContextHost`, with `rxjs` as their peer, which the reply interceptor imports), the runtime of the `validators` link (zod, yup, or class-validator with class-transformer) and, for types only, `@seampact/hooks` (ADR 0009). It uses explicit injection tokens with `@Inject`, never `emitDecoratorMetadata`, so any transpiler that supports NestJS's legacy decorators runs it. It never imports `@seampact/signed-webhooks`: the app's authenticate hook calls it. The runtime package is a production dependency: `@seampact/server-runtime`, its root, `/node` and `/nestjs` exports, at the generator's version (ADR 0025, G1). `seampact generate` refuses an app that does not install it (`runtime.missing`) or installs one of another `major.minor` or a lower patch (`runtime.version-mismatch`).

`createContractDocument` writes `openapi: '3.1.0'` when the config has no version or `DocumentBuilder`'s default `3.0.0`, and `autoTagControllers: false`; another version or `autoTagControllers: true` throws, naming the value. Under the default scope of the framework-route check, Swagger UI outside the api's base paths needs no `frameworkRoutes` entry; an api served at the root still lists them.
