# @seampact/codegen-express

Seampact target for Express 4 and 5: generates a router per api that checks access, input and replies around your handler map.

```sh
npm install --save-dev @seampact/codegen-express
```

Guide: https://jubasse.github.io/seampact/backend/express/

Generates an Express router per api that serves each contract route behind its access, validation and reply checks around your handler map, on Express 4 and 5, validating with zod.
